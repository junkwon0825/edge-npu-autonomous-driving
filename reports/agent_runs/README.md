# Development logs

Raw logs written during development, which was AI-assisted (coding agents ran the experiments under the
owner's direction and approval). They are kept for traceability, not as the project's public
documentation.

| File | Content |
|---|---|
| `failures.jsonl` | Failure ledger: every failed or quarantined run and every bug found, with its cause and fix |
| `task_table.md`, `task_state.json` | V1 task tracking |
| `latest_status.md`, `v2_latest_status.md`, `v3_latest_status.md` | Status snapshots at the end of each phase |

The engineering results live in `reports/v1_final_report.md`, `reports/v2_final_report.md` and
`reports/v3_final_report.md`. Measured data is in `reports/evidence/`.
